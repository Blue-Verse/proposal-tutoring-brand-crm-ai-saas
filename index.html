  • 학생·학원 행정 관리 — 학생/학부모 정보, 상담·결제·일정 관리(CRM)
  • AI 수업 리포트 자동 생성 — AI API 연동, 학부모 대상 리포트 자동 배포
  • 멀티테넌트 구조 — Supabase RLS로 선생님별 테넌트 데이터 완전 격리
  • 외부 API 4종 연동 — 결제선생(결제), Solapi(알림톡/문자), Notion(문서), AI(리포트)

  • 노코드 빌더 미사용 — 실제 코드 기반 개발, 소스코드/디자인 저작재산권 발주처 귀속(NDA 별도)

  • 멀티테넌트 우선 아키텍처 — 단일 브랜드 전환 단계부터 RLS 정책과 테넌트 스키마를 확정해, 향후 다중 선생님 확장 시 재설계 없이 확장

  • 관리 시스템·대상자 관리 경험 — 멀티테넌트 케어 관리, 어드민 대시보드, 승인 워크플로우를 다수 상용화 (학생 관리·학부모 커뮤니케이션 구조와 직결)
  • Lighthouse 90+ 성능 최적화 — Next.js App Router 서버 컴포넌트·이미지 최적화·SEO 메타 설계로 4개 항목 90점 목표 달성 프로세스 내재화

1. 프로젝트 배경 및 목적

  • 학원·과외 행정 업무(상담·결제·일정)를 자동화하고, AI 수업 리포트로 학부모 만족도를 높이는 것이 목표
  • 현재 운영 중인 단일 브랜드를 본 시스템으로 전환하며, 향후 다중 선생님이 각자 계정으로 사용하는 멀티테넌트 SaaS로 확장
  • 지원사업 일정에 맞춰 8월 14일까지 1차 마일스톤(공개 사이트) 달성이 최우선

  • [필수] 브랜드 공개 사이트(랜딩·소개·문의), 모바일 우선 반응형
  • [필수] CMS 콘텐츠 관리 — 페이지/섹션/게시물 직접 편집
  • [필수] SEO 메타·사이트맵, Lighthouse 90+ 최적화

3.2 학생 및 학원 행정 관리

  • [필수] 학생/학부모 정보 관리(CRM), 검색·필터
  • [필수] 상담 관리, 수업/일정 관리(캘린더)
  • [필수] 결제 관리 — 결제선생 API 연동(수강료 청구·영수·상태)
  • [필수] 알림 자동화 — Solapi 알림톡/문자(일정·결제·리포트)

3.3 AI 리포트 & 자동화

  • [필수] AI API 연동 수업 리포트 자동 생성(입력→생성→검수→발행)
  • [필수] Notion API 연동 리포트 아카이빙/배포
  • [선택] 리포트 템플릿/톤 커스터마이징

EZ-Approve — 전자결재 SaaS

기업용 SaaS / 관리자 포탈 · 약 9주

프로젝트 개요

다단계 전자결재·승인 워크플로우와 관리자 대시보드를 갖춘 기업용 SaaS. Next.js·TypeScript 풀스택으로 구축했습니다.

핵심 기능

  • 관리자 대시보드, 역할 기반 접근제어(RBAC, 7개 역할)
  • 토큰 기반 외부 셀프서비스 포탈, 리치 에디터
  • 50+ 페이지, 120-150 API 엔드포인트 규모의 어드민 시스템

본 프로젝트와의 유사점

공개사이트+CMS+관리자 대시보드+학생관리로 이어지는 다중 역할·권한 기반 관리 시스템 구조와 직결. Next.js/TypeScript 풀스택 어드민 개발 경험이 그대로 적용됩니다.

기술 스택

Next.js TypeScript NestJS RBAC Docker

Series-B — 펀드 관리 플랫폼

B2B 포탈 / AI 리포트 자동화 · 약 14개월

프로젝트 개요

다중 이해관계자(포탈) 대시보드와 AI 기반 보고서 자동 생성을 갖춘 대규모 관리 플랫폼. 데이터 격리·보안을 강도 높게 설계했습니다.

  • AI 투자 보고서 자동 생성(입력→생성→검수→발행)

  • 5계층 보안·데이터 격리, 200-300+ API 엔드포인트
